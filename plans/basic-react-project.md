# Basic React Project

Create an independent React test project at `projects/basic-react`.

## Delivery

- Use the Vite React TypeScript template with npm.
- Replace the default demo with a small responsive page: heading, short description, and a counter interaction.
- Do not create a todo application.
- Add Vitest, jsdom, and React Testing Library coverage for rendering and counter incrementing.
- Provide `dev`, `build`, `lint`, `test`, and `check` scripts, with `check` running lint and tests.

## Repository layout

- Add `projects/README.md` to define independent project conventions.
- Add `control-flows/README.md` as the reserved location for future custom Boatstack flows; do not implement one now.
- Update the root README with the layout and project commands.
- Update Boatstack build and test commands to execute the project build and check scripts.

## Verification

- Run the project check script and production build.
- Confirm Boatstack health after the configuration update.
