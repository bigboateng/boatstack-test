# Boatstack Test

An intentionally minimal repository for testing Boatstack setup and delivery control.

## Layout

- `projects/basic-react` — independent Vite React TypeScript test project.
- `control-flows` — reserved for future repository-local Boatstack flows.

## Basic React project

```sh
npm --prefix projects/basic-react install
npm --prefix projects/basic-react run dev
npm --prefix projects/basic-react run check
npm --prefix projects/basic-react run build
```
