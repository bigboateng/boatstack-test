# Add Todo Count Label

## Goal

Add a small visible todo-count label to the React todo app so the disposable
consumer run has one bounded product objective.

## Requirements

- Show the total number of todos beside the list heading.
- Use the existing todo state as the only source of the count.
- Keep the label correct after adding, completing, or deleting a todo.
- Follow the app's existing typography and spacing conventions.
- Add focused component tests for the initial count and count updates.

## Files

- `projects/basic-react/src/App.tsx`
- `projects/basic-react/src/App.css`
- `projects/basic-react/src/App.test.tsx`

## Verification

- Run `npm --prefix projects/basic-react run check`.
- Run `npm --prefix projects/basic-react run build`.
- Fix only failures attributable to this plan.
